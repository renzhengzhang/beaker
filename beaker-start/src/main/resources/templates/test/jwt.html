使用说明

1. 首先使用用户名密码进行JWT登录

2. 登录成功后会自动填充访问令牌和刷新令牌

3. 使用访问令牌调用受保护的API接口

4. 当访问令牌过期时，可使用刷新令牌获取新的访问令牌

5. 支持GET、POST、PUT、DELETE等HTTP方法
